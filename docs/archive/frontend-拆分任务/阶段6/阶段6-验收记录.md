## 8. 当前后端局限

以下能力后端未提供，前端未伪造入口：

- **订单查询未校验归属**：`GET /api/seckill/orders/{orderNo}` 按订单号查询，不比对当前用户，前端不据此做安全承诺。
- **无购物车**：原型购物车按钮、计数、移动端购物车入口已移除。
- **无收藏**：商品卡片心形按钮已移除。
- **无会员体系**：`会员价` 展示已移除。
- **无收货地址**：页脚与账户页标注「暂未开放」。
- **无普通商品订单**：订单页只展示秒杀订单。
- **无分类字典**：分类快捷入口为静态链接，`categoryId` 需手填数字。
- **无搜索建议接口**：建议面板只能使用本地词表。
- **无订单列表接口**：无「我的订单」页。
- **无商品删除接口**：测试数据只能下架，不能物理删除。
- **无管理员单条查询接口**：编辑页回填依赖列表快照或按页遍历。

## 9. 已知问题

1. **订单号格式与接口文档不一致**：文档示例 `SECKILL202610170001`，实际返回 `SK1792243963220-2-125`。前端只做字符串透传，不受影响；`docs/接口文档.md` 7.5 / 7.6 需同步修订。
2. **登录回跳曾出现双层嵌套**：`/login?redirect=/login?redirect=/seckill/113`。已修复为「位于登录页时不再叠加 redirect」，由 SiteLayout 的 `loginTarget()` 统一处理。
3. **Playwright 路由拦截需用完整后端地址**：`**/api/search**` 会同时命中 Vite 开发模块 `/src/api/search.ts`，导致前端页面加载失败。用例改用正则 `localhost:8080/api/search`。
4. **Vite 文件监听与测试目录冲突**：Playwright 写临时文件时 Vite 监听报 `EBUSY` 并退出，已在 `server.watch.ignored` 中排除 `tests/`、`test-results/`、`playwright-report/`。
5. **仅 Chromium 基线**：本轮只验收 Chromium 156，未做 Firefox / WebKit 矩阵。移动端项目使用 Chromium 的 Pixel 7 预设，不是真实 Safari。
6. **无压测基线**：前端只记录构建产物体积，不记录首屏性能指标。
7. **移动端页头搜索框曾被组件 scoped 样式覆盖**：SearchInput 的 .search-form { display: flex } 带 [data-v-*] 属性，特异性高于布局层的 .header-main > .search-form。已改用 .header-main > .search-form.search-form 提高特异性，实测 display 由 lex 变为 
one。
8. **管理端列表页面包屑曾重复**：/admin/products 显示为「管理端 / 商品管理 / 商品管理」，已让列表页自身即为末级分组。
