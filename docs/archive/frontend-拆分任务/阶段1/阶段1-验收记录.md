## 5. HTTP 客户端

| 检查项 | 实测结果 |
| --- | --- |
| `ApiResponse<T>` / `PageResult<T>` | 与接口文档 2.3、2.4 一致 |
| `ApiError` | 携带 `code`、`message`、`httpStatus`、`kind`、`data` |
| `kind` 取值 | `business` / `http` / `timeout` / `network` / `canceled` |
| 响应拦截顺序 | 先看 HTTP 状态码，再判 `code`；`code !== 0` 抛 `ApiError` |
| HTTP 401 | 清空登录态、跳 `/login` 并带回跳参数，1 秒内只处理一次 |
| HTTP 403 | 抛 `code = 403`，页面渲染无权限，不自动重试 |
| 超时 | 10s，抛 `kind = 'timeout'` |
| 网络异常 | 抛 `kind = 'network'` |
| 取消 | `AbortSignal` 透传，`kind = 'canceled'` 不进入错误态 |
| `upload` | `multipart/form-data`，字段名固定 `file`，不手工设置 `Content-Type` |
| `isApiError` | 类型守卫，供页面分支 |

实测：手工写入非法令牌后访问 `/me`，`localStorage` 中 `mall.token` 被清空且跳转 `/login`（Playwright 用例「401 清理登录态并跳转登录页」通过）。

## 8. 问题与已知事项

- pnpm 12 默认拒绝第三方构建脚本，需在 `.npmrc` 用 `only-built-dependencies[]=esbuild` 放行，否则 `vite build` 失败。
- Vite 6 起默认只监听 IPv6 回环，`http://localhost:5173` 在部分环境下不可达，`vite.config.ts` 显式指定 `host: '127.0.0.1'`。
- 原型第 14–42 行之外的字体依赖（Google Fonts CDN）与 Unsplash 远程图已替换：字体本地化，首屏主视觉改为本地 SVG。
- `/403` 页面当前由路由守卫重定向到 `name: 'forbidden'`，URL 显示为 `/403`。
