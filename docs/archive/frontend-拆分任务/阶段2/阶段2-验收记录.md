## 1. 接口实测

### 1.1 登录

```text
POST /api/auth/login
{"username":"user","password":"user123"}

{"code":0,"message":"成功","data":{
  "token":"eyJhbGciOiJIUzM4NCJ9...",
  "expiresIn":7200,
  "user":{"id":2,"username":"user","nickname":"普通用户","role":"USER"}
}}
```

### 1.2 错误密码

```text
{"code":1001,"message":"用户名或密码错误","data":null}
```

前端行为：停留在登录页，展示表单级错误「用户名或密码错误」，用户名保留、密码清空。

### 1.3 当前用户

```text
GET /api/auth/me   （Authorization: Bearer <token>）
{"code":0,"message":"成功","data":{"id":2,"username":"user","nickname":"普通用户","role":"USER"}}
```

### 1.4 商品列表

```text
GET /api/products?page=1&size=3
{"code":0,"message":"成功","data":{"total":13,"page":1,"size":3,"list":[
  {"id":14,"name":"李宁䨻科技跑鞋赤兔 7 Pro","brand":"李宁","categoryId":1001,"price":899.00,"stock":70,"status":1,"imageUrl":null},
  ...
]}}
```

商品 `id` 为主键，`imageUrl` 为 `null` 时前端走内联 SVG 占位，不发空地址请求。

### 1.5 下架 / 不存在商品

```text
GET /api/products/999999
{"code":2001,"message":"商品不存在","data":null}
```

前端渲染「商品不可用」占位页并给出返回列表入口，不显示空白页。

### 1.6 参数越界

```text
GET /api/products?page=1&size=101
HTTP 400
{"code":400,"message":"每页条数不能超过 100","data":null}
```

前端 `normalizeProductQuery` 在发请求前把 `size` 收敛到 1–100、`page` 收敛到 ≥ 1，越界值不会原样发出。

## 2. Playwright 实测

关键用例与结果（`pnpm test:e2e --project=chromium-desktop`）：

| 用例 | 结果 |
| --- | --- |
| 登录后可浏览商品，刷新后登录态不丢 | 通过（1.2s） |
| 未登录访问受保护页面跳转登录并带回跳参数 | 通过（0.4s） |
| 非法商品 ID 落到 404 | 通过（0.6s） |
| 401 清理登录态并跳转登录页 | 通过（0.4s） |
| 新增商品默认下架，上架后用户侧可见 | 通过（3.1s） |

### 2.1 刷新恢复登录态

登录后访问 `/me` → `page.reload()` → 仍停留在 `/me` 且展示用户名，未闪回登录页。

### 2.2 401 清态

在 `localStorage` 写入 `mall.token=invalid-token-value` 后访问 `/me`：
- 页面跳转 `/login`
- `localStorage.getItem('mall.token')` 返回 `null`

### 2.3 403 拦截

USER 令牌访问 `/api/admin/products`：`HTTP 403` + `{"code":403,"message":"权限不足"}`。前端渲染 `ForbiddenPage`，停留在管理端路径，不自动重试。

### 2.4 非法路由参数

`/products/abc`、`/products/0`、`/products/-1` 三者均渲染「页面不存在」。

## 3. 组件清单

| 组件 | props | 使用页面 |
| --- | --- | --- |
| `ProductCard` | `product`、`detailId?`、`badge?` | `/`、`/products`、`/search` |
| `PriceText` | `value`、`size?: 's' \| 'm' \| 'l'` | 商品卡片、详情、订单、活动 |
| `StockBadge` | `stock`、`threshold?` | 商品卡片、详情 |
| `StatusTag` | `status: 0 \| 1` | 商品详情、管理端列表 |
| `Pagination` | `page`、`size`、`total`、`disabled?`、`sizeOptions?` | `/products`、`/search`、`/seckill`、管理端列表 |
| `EmptyState` | `title`、`description?`、`actionText?` | 全部列表页 |
| `SkeletonBlock` | `width?`、`height`、`radius?` | 全部列表与详情页 |
| `ErrorState` | `error?`、`title?`、`description?`、`showRetry?` | 全部数据页 |

所有组件不直接发请求，数据与事件由页面传入；`components/index.ts` 统一导出。

商品卡片已移除会员价、收藏、加入购物车元素，Playwright 用例「商品卡片无会员价、收藏与加入购物车入口」通过。

## 4. 状态与错误处理

| 场景 | 实测表现 |
| --- | --- |
| 空结果（`total === 0`） | 「没有找到商品」+「清空筛选」按钮 |
| 请求失败 | `ErrorState`，按 `timeout` / `network` / 业务码区分文案，提供重试 |
| 加载中 | 骨架卡片，数量与 `size` 一致 |
| 切换筛选 | 重置到第 1 页并 `AbortController` 取消上一次请求 |
| 首屏失败 | 保留已渲染内容，只替换出错区块 |

## 5. 问题与已知事项

- 后端没有管理员单条商品查询接口，编辑页回填依赖列表快照与按页遍历（见阶段 5 记录）。
- `imageUrl` 在当前种子数据中为 `null`，前端全部走占位兜底，未出现破图。
- 商品列表的 `keyword` 长度上限 64 与搜索的 128 不同，两处常量分开定义（`PRODUCT_KEYWORD_MAX` / `SEARCH_KEYWORD_MAX`），单测已覆盖。
