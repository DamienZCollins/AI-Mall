# 阶段 0 拆分任务

> 目标：把原型的视觉与交互逐项对齐到现有后端能力，产出页面与接口的唯一映射，不创建前端工程。
> 状态：已完成
> 前置：`docs/frontend/总体方案.md`、`docs/接口文档.md`、后端阶段 2 到阶段 5 均已验收。

- [x] 统计 `frontend/原型.html` 的单文件构成：CSS 段、HTML 段、脚本段的行号边界
- [x] 列出页面骨架：页头、Hero、分类快捷入口、本周精选、生活提案、人气好物、页脚、移动端底部导航、移动端搜索弹层、Toast

## 0.4 字段与数据口径

- [x] 明确商品列表与详情使用 `id`，搜索结果使用 `productId`
- [x] 明确分页结构：`total`、`page`、`size`、`list`，页码从 1 开始
- [x] 明确金额按两位小数展示，时间为 `Asia/Shanghai` 本地时间
- [x] 明确活动状态 `0`–`3` 与订单状态 `1`–`4` 的展示文案

**验收**

- [x] 口径写入 `接口对齐.md`，后续页面不重复定义
