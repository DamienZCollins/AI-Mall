# 阶段 0 资源清单

> 用途：确定原型中字体、图片、图标、动效的来源与兜底策略，避免正式开发时才发现离线不可用。
> 依据：`frontend/原型.html` 第 9–11 行（远程字体）、第 2895 行与商品卡片（Unsplash 图片）、全文内联 SVG 图标。

## 1. 字体

原型从 Google Fonts 远程加载两套字体：

```html
<link href="https://fonts.googleapis.com/css2?family=Instrument+Sans:wght@400;500;600;700&family=Noto+Sans+SC:wght@400;500;600;700;800;900&display=swap" rel="stylesheet">
```

| 字体 | 用途 | 落地方式 | 兜底 |
| --- | --- | --- | --- |
| Instrument Sans | 拉丁字母、数字、英文标题 | 本地 `woff2`，`@font-face` + `font-display: swap` | 系统无衬线 |
| Noto Sans SC | 中文字体 | 本地 `woff2` 子集，或保留远程 + 连接失败降级 | `PingFang SC`、`Microsoft YaHei`、`sans-serif` |

结论：

- 中文字体体积大，首期保留原型中的字体栈回退顺序，不强制加载完整 Noto Sans SC。
- 拉丁字体可本地化，体积可控，随构建产物一起发布。
- 无论是否本地化，都必须保证字体加载失败时布局不塌陷。

## 2. 图片

| 来源 | 用途 | 落地方式 |
| --- | --- | --- |
| 后端 `imageUrl` | 商品图（列表、详情、搜索、秒杀、管理端） | 直接使用接口返回值，不二次拼接域名 |
| Unsplash 远程链接 | 原型 Hero、生活提案、占位商品图 | 只保留 Hero 与静态区，或替换为本地素材 |
| 本地素材 | 品牌视觉、图标、加载占位 | 放入 `src/assets/`，参与构建 |

要求：

- 所有 `<img>` 必须带 `width` / `height` 或固定宽高比容器，防止加载抖动。
- 必须有 `alt`；纯装饰图用 `alt=""`。
- 图片加载失败时显示占位块（品牌色底 + 商品名首字），不留空白。
- 列表与搜索结果的商品图使用 `loading="lazy"`；首屏 Hero 图不加懒加载。
- `imageUrl` 为空时同样走占位块，不请求空地址。

## 3. 图标

原型全部使用内联 SVG（`<svg class="icon" viewBox="0 0 24 24">`），没有图标字体依赖。

| 方案 | 结论 |
| --- | --- |
| 抽取为 Vue 组件 | 采用，统一 `size` 与 `stroke`，颜色继承 `currentColor` |
| 图标字体 | 不采用，增加字体依赖且不利于按需加载 |
| 第三方图标库 | 不采用，原型已有完整图标集 |

图标清单（按使用位置）：

| 图标 | 使用位置 |
| --- | --- |
| 搜索（圆 + 柄） | 页头搜索框、移动端搜索按钮 |
| 清空（×） | 搜索框清空 |
| 账户（人像） | 页头账户入口 |
| 购物车 | 移除 |
| 心形收藏 | 移除 |
| 加号 | 加入购物车，移除；抢购按钮改用独立样式 |
| 箭头左右 | 商品架翻页、搜索结果分页 |
| 首页/分类/我的（底部导航） | 移动端底部导航，按实际路由调整 |

## 4. 动效

原型定义的动效令牌：

| 令牌 | 取值 | 用途 |
| --- | --- | --- |
| `--ease` | `cubic-bezier(0.22, 1, 0.36, 1)` | 统一缓动 |
| `--fast` | `180ms` | 悬浮、颜色变化 |
| `--normal` | `360ms` | 弹层、Toast |
| `--slow` | `720ms` | 区块显现 |

要求：

- `prefers-reduced-motion: reduce` 时关闭位移与缩放动画，保留透明度变化。
- 滚动显现使用 `IntersectionObserver`，不可用时直接显示内容。
- 不引入动画库，纯 CSS 过渡足够。

## 5. 断点

| 断点 | 原型行为 |
| --- | --- |
| `max-width: 1280px` | `--gutter` 收窄到 40px |
| `max-width: 1100px` | 主导航与部分双列区块重排 |
| `max-width: 860px` | `--gutter` 28px，商品架改横向滚动 |
| `max-width: 600px` | `--gutter` 20px，`--header-h` 64px，底部导航出现 |
| `max-width: 370px` | 最小屏微调 |

统一在 `src/styles/tokens.css` 维护，页面不得自定义断点数值。

## 6. 可访问性基线

| 项 | 要求 |
| --- | --- |
| 焦点 | 所有可交互元素有可见 `focus-visible` 样式 |
| 屏幕阅读器 | 纯视觉文案用 `sr-only`，动态结果用 `aria-live="polite"` |
| 键盘 | Tab 顺序合理，弹层有焦点陷阱与 `inert`，Escape 可关闭 |
| 颜色 | 售罄、失败、超时不能只靠颜色表达，必须带文案或图标 |
| 动效 | 尊重 `prefers-reduced-motion` |
| 强制颜色 | `forced-colors: active` 下边框与文字仍可辨 |
