## 5. 资源策略结论

详见 `资源清单.md`，要点：

- 中文字体保留回退栈，不强制加载完整 Noto Sans SC
- 拉丁字体（Instrument Sans）已本地化为 woff2
- 商品图一律使用后端 `imageUrl`，必须带占位兜底
- 图标从内联 SVG 抽为组件，不引入图标库
- 断点 1280 / 1100 / 860 / 600 / 370 统一在 `tokens.css` 维护

## 6. 问题与已知事项

- 原型使用远程字体与 Unsplash 图片，离线打开时首屏会退化；正式开发已把字体本地化、首屏主视觉换成本地 SVG。
- 原型分类文案与后端 `categoryId` 无对应关系，首期不能做真实分类筛选。
- 原型的购物车、收藏、会员价为纯前端交互，没有后端语义，不进入验收。
- 后端订单查询接口不校验订单归属，前端无法据此提供用户级安全保证，已在阶段 4 与阶段 6 记录中保留该风险。
- `生活提案` 区块无后端支撑，实际实现中移除。
