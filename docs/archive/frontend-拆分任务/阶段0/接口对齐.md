# 阶段 0 接口对齐

> 用途：前端页面、接口、权限、错误码的唯一映射表。
> 依据：`docs/接口文档.md`（接口与业务码）、`docs/frontend/总体方案.md` 第 4 章（路由）。
> 口径：以运行中的 OpenAPI 文档为准；本文与 OpenAPI 不一致时，先修订本文再改页面。

## 1. 基础约定

| 项 | 取值 | 说明 |
| --- | --- | --- |
| Base URL | `http://localhost:8080` | 由 `VITE_API_BASE_URL` 注入，不写死在代码里 |
| 业务前缀 | `/api` | 认证、商品、搜索、秒杀都在这之下 |
| 鉴权头 | `Authorization: Bearer <token>` | 令牌有效期由后端 `JWT_EXPIRE_MINUTES` 决定 |
| 统一响应 | `{ code, message, data }` | `code === 0` 才是业务成功 |
| 分页结构 | `{ total, page, size, list }` | 页码从 1 开始 |
| 时间格式 | `2026-10-17T10:00:00` | 本地时间，时区 `Asia/Shanghai` |
| 金额 | JSON 数字 | 展示统一两位小数 |

### 1.1 必须同时检查的两层结果

业务失败可能返回 HTTP 200，因此每个请求都必须先看 HTTP 状态码，再看 `code`：

| HTTP | 业务码 | 前端动作 |
| --- | --- | --- |
| 200 | 0 | 正常渲染 |
| 200 | 非 0 | 按业务码表处理，不当作网络错误 |
| 400 | 400 | 展示参数校验提示 |
| 401 | 401 | 清理令牌，跳转 `/login` |
| 403 | 403 | 展示无权限，不重试 |
| 500 | 500 | 展示系统错误，可重试 |

| 路由 | 页面 | 权限 | 主接口 | 依赖业务码 |
| --- | --- | --- | --- | --- |

| `/products` | 商品列表 | 公开 | `GET /api/products` | `400` |
| `/products/:id` | 商品详情 | 公开 | `GET /api/products/{id}` | `2001` |
| `/search` | 搜索结果 | 公开 | `GET /api/search` | `3001`、`3002`、`400` |

## 4. 字段口径

### 4.1 商品 `id` 与搜索 `productId`

| 来源 | 主键字段 | 跳转目标 |
| --- | --- | --- |
| `GET /api/products` | `id` | `/products/:id` |
| `GET /api/products/{id}` | `id` | 自身 |
| `GET /api/search` | `productId` | `/products/:productId` |

搜索结果不得直接当作商品模型复用，两者字段集合不同：搜索结果没有 `description`、`status`，多出 `score`、`hasVector`。

### 4.2 枚举展示文案

活动状态：

| 值 | 文案 | 用户侧按钮 |
| --- | --- | --- |
| `0` | 未开始 | 禁用，显示开始时间 |
| `1` | 进行中 | 可点击抢购（需 `remainingStock > 0`） |
| `2` | 已结束 | 禁用 |
| `3` | 已关闭 | 禁用 |

订单状态：

| 值 | 文案 | 支付按钮 |
| --- | --- | --- |
| `1` | 待支付 | 显示（含倒计时） |
| `2` | 已支付 | 不显示 |
| `3` | 已取消 | 不显示 |
| `4` | 超时取消 | 不显示 |

抢购结果 `state`：

| 值 | 文案 | 前端动作 |
| --- | --- | --- |
| `QUEUING` | 排队中 | 继续轮询 |
| `SUCCESS` | 抢购成功 | 停止轮询，用 `orderNo` 进订单 |
| `FAILED` | 未抢到 | 停止轮询 |

### 4.3 参数上限差异

| 接口 | `size` 上限 | `keyword` 上限 |
| --- | --- | --- |
| `GET /api/products` | 100 | 64 |
| `GET /api/search` | 50 | 128 |
| `GET /api/seckill/activities` | 100 | 无 |

前端不得使用同一套常量覆盖三种上限。

## 5. 业务码处理表

| 业务码 | 含义 | 前端动作 |
| --- | --- | --- |
| `1001` | 用户名或密码错误 | 表单内提示，不清空用户名 |
| `1002` | 用户不存在 | 清理登录态，回登录页 |
| `1003` | 账号已被禁用 | 提示联系管理员 |
| `2001` | 商品不存在 | 商品不可用占位页 |
| `2002` | 商品状态不合法 | 行内提示，刷新列表 |
| `2003` | 图片上传失败 | 保留本地预览，允许重试 |
| `3001` | 文本向量化失败 | “语义检索暂不可用”，可重试 |
| `3002` | 搜索服务暂不可用 | “搜索服务暂不可用”，可重试 |
| `4001` | 秒杀活动不存在 | 活动不可用占位页 |
| `4002` | 活动尚未开始 | 按钮禁用，显示开始时间 |
| `4003` | 活动已结束 | 按钮禁用 |
| `4004` | 已售罄 | 展示售罄，不重试 |
| `4005` | 同一活动限购 | 展示限购说明，不重试 |
| `4006` | 秒杀订单不存在 | 订单不可用占位页 |
| `4007` | 订单状态不允许该操作 | 提示并刷新订单状态，不反复点击 |
| `4008` | 活动时间不合法 | 表单字段级提示 |
| `4009` | 秒杀价必须低于原价 | 表单字段级提示 |
| `4010` | 排队服务暂不可用 | 提示稍后重试，允许重新发起抢购 |
| `4011` | 抢购请求处理中 | 提示等待，转入结果查询 |

## 6. 静态内容归属

以下内容没有后端接口，只作为视觉与文案存在：

| 内容 | 处置 |
| --- | --- |
| Hero 品牌区 | 静态文案与本地图片 |
| 分类快捷入口（数码/家居/个护/服饰/食品/更多） | 静态链接，不传 `categoryId` |
| 生活提案区块 | 静态内容，或首期移除 |
| 页脚品牌故事、帮助中心、配送说明 | 静态文案，链接不指向未实现页面 |
| 会员价、加入购物车、收藏 | 移除，不保留可点击假入口 |
| 购物车计数与移动端购物车入口 | 移除 |
