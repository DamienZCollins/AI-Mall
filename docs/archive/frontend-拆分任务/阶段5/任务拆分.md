## 5.2 管理端商品接口封装

- [x] `src/api/admin.ts` 集中定义管理端请求函数与 DTO，页面不手写路径
- [x] `listAdminProducts(params)` → `GET /api/admin/products`，参数 `page`、`size`、`keyword`、`categoryId`、`status`
- [x] `status` 取 `0` 下架 / `1` 上架，不传表示全部，用 `undefined` 表达而非空字符串（后端绑定 `Integer` 失败返回 HTTP 400）；`keyword` 最长 64
- [x] `createAdminProduct(payload)` → `POST /api/admin/products`，请求体不含 `status`，新增后为下架
- [x] `updateAdminProduct(id, payload)` → `PUT /api/admin/products/{id}`，字段为 `null` 表示不修改；请求体类型不含 `status`，用 TypeScript 禁止通过编辑接口改上下架
- [x] `changeProductStatus(id, status)` → `PATCH /api/admin/products/{id}/status`，请求体 `{ status }`
- [x] `uploadProductImage(file)` → `POST /api/admin/products/images`，`FormData` 字段名 `file`；`reindexSearch()` → `POST /api/admin/search/reindex`，`data` 为重建数量
- [x] HTTP 200 且 `code !== 0` 统一归入 `ApiError`，页面只按业务码分支，网络错误与业务错误文案分开

**说明**：`PUT` 的 `name` 在后端用 `StringUtils.hasText` 判断，空串等同不修改，名称无法被清空；`brand`、`description`、`sellingPoint`、`imageUrl` 传 `null` 表示不修改，传 `""` 才是清空。

**验收**

- [x] 每个页面只调用本文件导出的函数，仓库内没有页面内拼写的 `/api/admin` 路径
- [x] 不选状态时请求 URL 不含 `status=`；类型检查能拦住向 `PUT` 请求体传 `status`

## 5.5 商品图片上传

- [x] `ImageUploader.vue` 调用 `POST /api/admin/products/images`，`FormData` 字段名 `file`，不手工设置 `Content-Type`，让浏览器生成 boundary
- [x] 本地预校验类型 `image/png`、`image/jpeg`、`image/gif`、`image/webp` 并同步校验扩展名；大小 ≤ 5 MB（`5 * 1024 * 1024` 字节），超限不发请求
- [x] 用 `URL.createObjectURL` 生成预览，替换或取消时 `revokeObjectURL` 释放；`onUploadProgress` 展示上传百分比，上传中禁用「选择文件」与「保存」
- [x] 成功后用返回 URL 替换预览并写入表单 `imageUrl`；失败保留本地预览并提供重试；已上传图片可删除，删除后 `imageUrl` 置空
- [x] `2003` 且 `message` 为兜底文案「图片上传失败」：提示「图片存储服务不可用（RustFS 未启动或 bucket 不可用），请确认服务后重试」；`message` 为具体原因（如「只支持 png、jpg、gif、webp 图片」「图片大小不能超过 5MB」「上传文件为空」）时原样展示后端文案
- [x] 只有网络中断、超时、跨域失败才显示「网络错误」，与 `2003` 分开

**说明**：后端按文件头识别类型，前端按 MIME 与扩展名预校验，两者不等价。扩展名正确但内容不是图片时预校验通过、后端返回 `2003`，须按上一条规则提示，不能报成网络错误。

**验收**

- [x] 停掉 RustFS 后上传显示基础设施不可用提示，不是「网络错误」；超过 5 MB 的文件在本地被拦截，请求未发出
- [x] 上传后页面可预览，返回 URL 粘到浏览器可访问；失败后重试无需重新选文件

## 5.7 活动表单校验

| 字段 | 控件 | 必填 | 前端校验 | 后端依据 | 提示文案 |
| --- | --- | --- | --- | --- | --- |
| `productId` | 下拉选择 | 是 | 只能选上架商品，不可手输 | 必须是上架商品，否则 `2001` | 请选择上架商品 |
| `title` | 单行文本 | 是 | `trim()` 后非空，≤128 | `@NotBlank`、`@Size(max = 128)` | 活动标题不能为空 / 活动标题长度不能超过 128 |
| `seckillPrice` | 数字输入 | 是 | ≥0.01，整数位 ≤8，小数位 ≤2，且低于商品原价 | `@DecimalMin("0.01")`、`@Digits(8, 2)`，不低于原价返回 `4009` | 秒杀价必须大于 0 / 秒杀价格式不正确 / 秒杀价必须低于商品原价 |
| `totalStock` | 整数输入 | 是 | >0 | `@Min(1)` | 活动总量必须大于 0 |
| `perUserLimit` | 整数输入 | 否 | >0，默认 `1` | `@Min(1)`，不传默认 `1` | 限购数量必须大于 0 |
| `startTime` | `datetime-local` | 是 | 必填 | `@NotNull` | 开始时间不能为空 |
| `endTime` | `datetime-local` | 是 | 必填，晚于 `startTime` | `@NotNull`，否则 `4008` | 结束时间必须晚于开始时间 |
| `payTimeoutMinutes` | 整数输入 | 否 | >0，默认 `15` | `@Min(1)`，不传默认 `15` | 超时分钟数必须大于 0 |
| `status` | 开关 | 仅编辑 | `1` 启用、`0` 停用 | 编辑接口的配置开关 | — |

- [x] 商品下拉取 `GET /api/products`（只返回上架商品）并分页取全，切换商品后重校验价格关系
- [x] 前端拦截 `seckillPrice >= originalPrice`，原价取所选商品的 `price`，不自行估算
- [x] 时间控件输出 `2026-10-17T10:00:00`（本地时间，不带时区偏移），由 `src/utils/datetime.ts` 的 `toLocalDateTimeInput`（截到分钟填控件）与 `fromLocalDateTimeInput`（补齐秒后提交）互转：`2026-10-17T10:00:00` ↔ `2026-10-17T10:00`

- [x] `4008`、`4009` 回填到对应字段错误位置并保留后端 `message`；未保存离开的确认与 5.4 共用同一套逻辑

## 本阶段不做

- 不做商品删除、批量操作与多图：后端只有单图与维护接口
- 不做分类字典与分类树：后端无分类接口，`categoryId` 手填数字
- 不改活动的秒杀价、总量与限购：编辑接口只接受 `title`、`startTime`、`endTime`、`status`
- 不做用户、角色与权限管理页面，不引入 UI 组件库，不新增后端接口
