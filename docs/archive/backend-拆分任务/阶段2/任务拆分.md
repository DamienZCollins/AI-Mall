## 目录结构

```text
com.mall
├── common
│   ├── exception     统一异常与全局异常处理
│   ├── result        统一返回体、错误码、分页结构
│   └── security      JWT 工具、当前登录用户（跨模块共用，不依赖业务模块）
├── config
│   ├── security      Spring Security 过滤链与认证过滤器
│   └── storage       S3 客户端与 bucket 初始化
├── user              用户、登录
│   ├── controller / service / mapper / entity / dto
└── product           商品、商品图片
    ├── controller / service / mapper / entity / dto
```
