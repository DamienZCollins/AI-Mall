> 环境：Windows + Java 21（Liberica 21.0.4）+ Spring Boot 3.5.16

## 1. 验收命令

```bash
# 重建含 ik 分词的 ES 镜像并启动
docker compose build elasticsearch
docker compose up -d --wait elasticsearch

# 写入初始数据
docker exec -i mall-mysql mysql -uroot -p1234 --default-character-set=utf8mb4 mall < sql/schema.sql
docker exec -i mall-mysql mysql -uroot -p1234 --default-character-set=utf8mb4 mall < sql/data.sql

# 构建与启动
mvn clean package -DskipTests
set -a && . ./.env && set +a
java -jar target/mall-0.0.1-SNAPSHOT.jar

# 建立索引
curl -X POST http://localhost:8080/api/admin/search/reindex -H "Authorization: Bearer <admin token>"

# 检索效果验收
python scripts/checks/search_check.py

# 同步链路与阶段 2 回归
python scripts/checks/sync_check.py
```

## 6. 过程中的问题与处理

| 问题 | 现象 | 处理 |
| --- | --- | --- |
| ik 分词插件缺失 | 容器无插件，中文被切成单字 | 自建 `docker/elasticsearch/Dockerfile` 安装 analysis-ik 8.17.6，固化到镜像，容器重建不丢 |
| RRF retriever 需付费许可 | `security_exception: current license is non-compliant for [Reciprocal Rank Fusion (RRF)]`，basic 许可下 403 | 改为应用层 RRF，两路召回仍由 ES 执行，见 3.7 的方案变更说明 |
| 索引名与别名重名 | `alias name [mall_product] self-conflicts with index name` | 原设计把 `.env` 的 `ELASTICSEARCH_INDEX_PRODUCT` 当索引名用，而它本就是别名；改为环境变量即别名，索引名由别名加 `_v1` 派生 |
| `updateTime` 写入失败 | `failed to parse field [updateTime] of type [date]`，纳秒精度超出秒级格式，整批 14 条全部写入失败 | 该字段对检索无作用，从 mapping、文档与索引服务中移除 |
| 同步后立刻搜索读不到 | ES 默认 1 秒刷新间隔 | 单文档写入与删除加 `refresh=wait_for`，保证「上架即可搜到」，代价是写入延迟略微增加 |
| 配置缺 `spring.elasticsearch.uris` | 启动失败 `Could not resolve placeholder` | 阶段 0 模板有此键，阶段 1 建应用配置时遗漏，补回并接上 `ELASTICSEARCH_HOST` / `PORT` |

## 7. 已知事项

- **kNN 没有相关度下限**：kNN 恒返回 k 个最近邻，不设阈值。查「冬天保暖」时「速干透气洞洞鞋」也会进入候选，只是名次靠后。若要过滤弱相关结果，需引入相似度阈值或 score 截断。
- **深分页**：融合需要在内存中完成，单路候选窗口上限 200 条，`page × size > 100` 时结果会不完整。当前数据规模无影响，商品量上来后应改用原生 RRF 或专用融合层。
- **重建索引是全量且同步的**：一次请求内逐页读 MySQL、逐条调 embedding 再批量写入。14 条耗时约 2.7 秒，商品量大时需改为带游标的异步任务。
- **BM25 权重靠经验**：`name^3 / brand^2 / 其余^1` 是拍的，没有做相关性评估集调参。
- **embedding 失败降级**：向量生成失败时文档仍写入，但 `hasVector=false`，只参与 BM25 召回，不被 kNN 召回。需要重新向量化时调用重建索引接口。
- **删除商品不删索引文档**：商品被物理删除后 ES 文档残留，靠 `status` 过滤兜住。当前没有删除商品的接口，暂不影响。
