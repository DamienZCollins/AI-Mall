## 3.7 RRF 融合排序

- [x] 应用层实现 RRF：`score = Σ 1 / (k + rank)`，k 取 60
- [x] 按名次融合而非按原始分，BM25 分与余弦相似度不可比
- [x] 两路各取 size × 2 的候选窗口，窗口上限 200
- [x] 只在一路出现的商品按单路得分参与排序

**方案变更**：原计划使用 ES 原生 `rrf` retriever。实测 basic 许可下该特性返回
`security_exception: current license is non-compliant for [Reciprocal Rank Fusion (RRF)]`，
属于铂金 / 企业版特性。改为两路召回仍由 ES 执行、融合在应用层完成，不引入付费依赖。
代价是请求数从 1 次变 2 次，且融合需在内存中完成。

**验收**

- [x] 两路结果经融合后排序合理
- [x] 只在一路出现的商品也能进入结果
