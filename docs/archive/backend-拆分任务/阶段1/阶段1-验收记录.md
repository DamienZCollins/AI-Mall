## 3. 数据库连接验证

应用启动后 MySQL 进程列表中存在 `dev@localhost` 连接到 `mall` 库的连接，说明数据源真实生效：

```sql
SELECT USER(), DB FROM information_schema.processlist WHERE USER='dev';
-- dev@localhost | mall
```

## 4. 统一返回体与异常验证

访问不存在的路径：

```text
GET /not-exist  ->  HTTP 404
{"code":404,"message":"资源不存在","data":null}
```

未使用统一异常处理时该场景会返回 500，已通过 `NoResourceFoundException` 处理修正。

## 6. 已知事项

- 启动时出现 `No MyBatis mapper was found in '[com.mall.**.mapper]'` 警告：阶段 1 尚无 mapper，阶段 2 建表后自然消失。
- springdoc 提示 `/v3/api-docs` 与 `/swagger-ui.html` 默认启用，本地开发需要，不关闭。
- 分页插件位于独立模块 `mybatis-plus-jsqlparser`，MyBatis-Plus 3.5.9+ 必须单独引入，否则 `PaginationInnerInterceptor` 编译失败。
