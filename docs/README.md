# 文档索引

本目录是项目文档的唯一入口。跨端共享的文档放在本层，各端文档按 `backend/`、`frontend/` 分包，
过程记录统一归档在 `archive/`。

## 公共文档

| 文件 | 内容 |
| --- | --- |
| `接口文档.md` | 接口清单、业务码与错误约定，前后端共用 |
| `压测报告.md` | 秒杀异步化压测：环境、方法、两轮数据、瓶颈分析与局限 |
| `screenshots/` | README 演示截图（11 张，JPEG） |
| `diagrams/` | 架构图、秒杀链路时序图、检索数据流图（archify 生成） |

## backend/

| 路径 | 内容 |
| --- | --- |
| `backend/总体方案.md` | 模块划分、技术选型与核心链路设计 |
| `backend/开发路径.md` | 开发顺序与交付物清单 |

## frontend/

| 路径 | 内容 |
| --- | --- |
| `frontend/总体方案.md` | 页面、组件、数据流与开发阶段划分 |
| `frontend/开发路径.md` | 前端开发顺序 |
| `frontend/原型.html` | 设计原型（浏览器直接打开） |

## archive/

过程文档，不作为项目说明的入口，保留用于追溯。

| 路径 | 内容 |
| --- | --- |
| `archive/backend-拆分任务/` | 后端阶段 0~6 任务拆分与验收记录 |
| `archive/frontend-拆分任务/` | 前端阶段 0~6 任务拆分与验收记录 |
| `archive/秒杀异步化压测对照.md` | 秒杀压测数字速查（已并入 `压测报告.md`） |
| `archive/阶段0-环境说明.md` | 早期仓库与环境说明（内容已并入总体方案） |

## 约定

1. 新增文档先判断归属端，写入对应子目录，不新建 `backend/docs/` 或 `frontend/docs/`。
2. 文档内引用其他文档时使用仓库根相对路径，例如 `docs/frontend/总体方案.md`。
3. 阶段任务拆分与验收记录只新增到 `archive/`，不再作为项目说明的一部分维护。
